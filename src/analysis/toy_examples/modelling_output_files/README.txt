
The description of these files correspond to the following folder: src/analysis/toy_examples/modelling_output_files

"coda.complN.RData" - Raw mcmc output file with subnational population sizes by age, sex, oblast and time
"coda.complNijast.RData" - Raw mcmc output file with mobility patterns by age, sex, oblast and time
"tidying_model_output.R" - R script to clean raw mcmc output
"mod_output_pop.csv" - Cleaned output file with subnational population sizes by age, sex (1="male", 2="female"), oblast and time
"mod_output_mob.csv" - Cleaned output file with with mobility patterns by age, sex (1="male", 2="female"), oblast and time
