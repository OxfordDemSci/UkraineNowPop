# Source Code (src)

This folder contains all of the source code in the repository, organised based on the use of the code.  

`./helpers/` R and Python functions that can be loaded into various scripts to help with common tasks.  
`./data_prep/` Scripts used to prepare data for analysis.  
`./analysis/` Scripts used for data analysis (e.g. population nowcasting models).  
`./dashboard/` Source code for the Ukraine NowPop dashboard.  
`./sandbox/` Experimental code for troubleshooting and works-in-progress.
